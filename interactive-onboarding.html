User Registration

Register a new user account using the test credentials.

Actions:
  1. Click "Sign Up" or "Register" in the navigation
  2. Fill in the registration form with the test credentials above
  3. Submit the form
POST /api/auth/register { "email": "onboarduser@example.com", "firstName": "onboarduser", "lastName": "onboarduser", "password": "onboarduser" }
What to observe:
  • Registration form appears with required fields
  • Success message after submission
  • Redirect to login page or auto-login

User Login

Authenticate with the newly created account.

Actions:
  1. Navigate to login page (if not auto-logged in)
  2. Enter email and password
  3. Click "Login" or "Sign In"
POST /api/auth/login { "email": "onboarduser@example.com", "password": "onboarduser" }
What to observe:
  • Login form with email and password fields
  • Successful authentication
  • JWT token stored (check DevTools > Application > Local Storage)
  • Navigation shows logged-in state

Create Order

Complete the checkout process and create an order.

Actions:
  1. Click "Checkout" or "Create Order"
  2. Fill in any required information
  3. Confirm the order
POST /api/orders { "items": [{"productId": 1, "quantity": 1}] }
What to observe:
  • Order confirmation page
  • Order ID displayed
  • Order summary with items
  • Total amount
  • Success message
  • Cart cleared
